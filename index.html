About Me

I’m a robotics engineer passionate about bioinspired design, intelligent systems, and hands-on innovation. My experience spans both technical and creative fields—from building advanced robotic systems and perception pipelines to editing a literary magazine and speaking publicly about AI. I’m especially interested in modular robotics, soft robotic systems, and sustainable technologies that combine engineering precision with adaptable, human-centered design.

Restaurant Manager App — Multi-Role GUI App (Python, SQLite3, OOP)

  • Developed a comprehensive restaurant management system using Python and Tkinter with a focus on modularity, usability, and scalability.
  • Created role-based login functionality for admins, managers, waiters, cooks, and customers, each with unique privileges and screen layouts.
  • Built fully functional GUI panels for user sign-up, menu management, order placement, billing, and user account control.
  • Implemented extensive form validation (e.g., input types, field completeness, unique credentials, format checks) to minimize user error.
  • Designed and managed a SQLite3 database with four main tables: Users, Menu, Orders, and Ingredients.
  • Integrated OOP (Object-Oriented Programming) principles for better structure and reusability across modules.
  • Created features for dynamic screen updating: interface elements update in real-time as users, menu items, or orders change.
  • Designed GUI with clear layouts, labels, and functional screens, ensuring consistent UX across user roles.
  • Used threading and modular programming to keep the application responsive and maintainable.
  • Built for future extensibility with potential for web or mobile integration using frameworks like Flask or Django.
